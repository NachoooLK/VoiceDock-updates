# VoiceDock para Mac

VoiceDock permite dictar texto y pegarlo en el campo activo, o copiarlo al portapapeles. Este repositorio aloja los ZIP de instalación y el catálogo de actualizaciones.

**[Descargar la última versión](https://github.com/NachoooLK/VoiceDock-updates/releases/latest)**

Requiere un Mac con **Apple silicon**, **macOS 14 o posterior** y **Codex instalado con una sesión de ChatGPT iniciada**.

## Instalar

1. Abre la página de descarga y descarga el ZIP para Apple silicon.
2. Descomprime el ZIP y arrastra **VoiceDock.app** a **Aplicaciones**.
3. Abre VoiceDock. En sus ajustes, comprueba que detecta tu sesión de ChatGPT en Codex.
4. Concede acceso al **micrófono** cuando macOS lo solicite. Activa **VoiceDock** en **Ajustes del Sistema → Privacidad y seguridad → Accesibilidad** para pegar en otras aplicaciones.
5. Coloca el cursor en un campo de texto y pulsa **Option + Espacio** para empezar a dictar; pulsa de nuevo para terminar. Puedes cambiar el atajo en los ajustes.

Sin Accesibilidad, VoiceDock puede transcribir y copiar el resultado al portapapeles.

## Actualizar

Si instalaste un ZIP anterior a la versión **0.2.0**, instala esta versión manualmente una vez para incorporar el actualizador.

Después, abre el menú de VoiceDock en la barra de menús y elige **«Buscar actualizaciones…»**. También puedes hacerlo en **Ajustes → General → Actualizaciones**, donde puedes activar o desactivar **«Buscar actualizaciones automáticamente»**.

La app pide tu aprobación para instalar. Si estás dictando, transcribiendo o tienes un resultado pendiente de recuperar, la instalación espera a que termines o lo resuelvas.

Las notas de cada versión indican su comprobación de firma y notarización de Apple. El catálogo de actualizaciones se publica después de verificar el ZIP final de esa versión.
